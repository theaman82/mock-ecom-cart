🛒 E-Com Cart

A simple full-stack E-commerce cart web app built using React (frontend), Node.js + Express (backend), and MongoDB (database).
It allows users to view products, add items to the cart, update quantities, and proceed to checkout — all in real time.

🚀 Features

🧩 Product Listing — Displays all products with images, prices, and discounts.

🛍️ Add to Cart — Add products with quantity handling and live total updates.

💸 Discount Handling — Shows both regular and discounted prices.

🧮 Cart Summary — Displays total price and total discount.

🧾 Checkout — Generates a receipt with user info and purchase details.

📱 Responsive Design — Mobile-friendly UI with hamburger dropdown navigation.

🌱 Mock Data Seeding — Auto-seeds MongoDB with sample product data.

🛠️ Tech Stack : 
Layer	Technology
Frontend	React, Tailwind CSS, Axios, React Router DOM
Backend	Node.js, Express.js
Database	MongoDB with Mongoose
Notifications	React Hot Toast
Dev Tools	Nodemon, Vite
